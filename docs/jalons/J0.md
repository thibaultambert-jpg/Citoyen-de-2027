# J0 — Fondations

## Réalisé

- Build Gradle multi-modules : `build-logic` (plugins de convention `citoyen.*`), catalogue de versions,
  wrapper Gradle 9.7.1 (sha256 épinglé).
- Modules de §4 : `:app`, `:core:model`, `:core:database`, `:core:data`, `:core:network`, `:feature:candidates`,
  `:feature:candidate`, `:feature:compare`, `:feature:ask`, `:feature:institutions`, `:feature:about`, `:rag`, `:llm`.
  Modules ajoutés : `:core:designsystem` (thème et composants partagés par les features), `:core:testing`
  (fixtures fictives), `:tools:neutrality-check` (garde-fou de build, non embarqué).
- minSdk 29, targetSdk 36, compileSdk 37, ABI `arm64-v8a` seule, Java/Kotlin 17.
- Thème Material 3 neutre (ardoise désaturée, pas de couleur dynamique, pas de vert/rouge sémantique), avatar à
  initiales identique pour tous, navigation adaptative (`NavigationSuiteScaffold` : barre ou rail) vers 5 sections,
  route typée de fiche candidat. Écrans en attente avec texte neutre.
- Modèle : `Candidate`, `CandidacyStatus` (DECLARE/RETIRE/OFFICIEL), `DataCoverage` (toutes facettes obligatoires),
  `SourceRef` (HTTPS obligatoire), `ProgramStatus`, `CandidateOrder` (alphabétique par défaut, collation française ;
  aléatoire à graine stable).
- Fixtures fictives Candidat A, B, C (URL en `.invalid`), avec tests qui le garantissent.
- Règles : ktlint (Spotless), Android Lint (`abortOnError`, `checkDependencies`, `HardcodedText` en erreur),
  scan de neutralité des `strings.xml` et de `llm/prompts/*.txt` contre `config/neutrality/evaluative-terms-fr.txt`.
- Manifeste : pas de permission INTERNET, `allowBackup=false`, `usesCleartextTraffic=false`.
- `THIRD_PARTY.md`, CI GitHub Actions (`.github/workflows/build.yml`).

## Décisions

- Versions alignées sur android/nowinandroid (combinaison testée en CI, oct. 2026) : AGP 9.3.2 (Kotlin intégré),
  Kotlin 2.3.0, KSP 2.3.4, Hilt 2.59 ; BOM Compose stable 2026.09.00 ; JUnit 5.14.4.
- Icônes : 6 Material Symbols copiés en vecteurs XML plutôt que `material-icons-extended` (taille d’APK).
- JUnit 5 aussi pour les tests unitaires Android (`useJUnitPlatform()`).
