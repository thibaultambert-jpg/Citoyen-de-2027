# J3 — Fiche complète : mandats, votes filtrables, prises de parole

## Réalisé

**Pipeline (schéma de pack v2)**
- Mandats gouvernementaux (AN, AMO30 `GOUVERNEMENT`) ajoutés aux mandats AN, Sénat, PE et locaux (RNE) ;
  libellé d’organe officiel (`libelleAbrege`).
- Votes : type de scrutin (`ballot_subject` : amendement, article, ensemble, motion, autre) déterminé par
  règles explicites sur l’intitulé officiel du scrutin, `OTHER` sinon (jamais deviné).
- Prises de parole : interventions en séance plénière du PE (`/speeches?person-id=`, lien ELI) ; discours
  publics vie-publique (métadonnées + lien officiel, pas de texte intégral), rattachés uniquement via le nom
  saisi à la main `vie_publique_name` d’`identities.yaml` ; les qualités relevées sont listées dans
  `report.json` pour relecture.
- Couverture « discours » calculée (`PARTIAL` dès qu’une prise de parole existe, aucune source n’étant
  exhaustive).

**App**
- Room v3 : `speeches`, `votes.ballot_subject` ; lecteur de pack v2, refus des autres versions.
- Fiche : onglets Mandats (frise du plus récent au plus ancien, assemblée, période, source), Votes
  (avertissement sur les limites : scrutins publics seulement, un vote « contre » peut viser une autre
  disposition ; filtres assemblée, année, type, position ; type de scrutin et lien officiel sur chaque
  ligne ; icônes et couleurs neutres), Prises de parole (séance / déclaration officielle, date, lien),
  Sources et méthode. Programme et Mise en regard restent en attente (J4).
- Positions affichées dans un vocabulaire français neutre, à partir des valeurs publiées.

## Tests
